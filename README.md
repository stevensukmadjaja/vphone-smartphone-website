**V-Phone Smartphone Website**

This project was created for the Human–Computer Interaction course at Bina Nusantara University to design a digital platform for V-Phone, a smartphone company that wants to present its products in a clear and accessible way. The website was built using HTML, CSS, JavaScript, and Figma, and includes five pages: Home, Products, Promotions, About Us, and Register. It provides an image slider, product categories, product filtering, interactive product details, promotional information, responsive navigation, and a registration form with validation. During the development process, I learned how to turn a Figma design into a working website, organize multiple pages and assets, and connect each page through a consistent navigation system. I also practiced creating responsive layouts, designing interfaces for smaller screens, and using JavaScript to build features such as image sliders, product filters, interactive overlays, page transitions, and form validation. Through this project, I gained a better understanding of how design and programming work together, while also learning to consider the user’s perspective when creating a clear, consistent, and comfortable website experience.
